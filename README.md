# 智能合约状态依赖引导模糊测试实验

本仓库的论文整理入口是 [`paper-ready/`](paper-ready/)。

建议阅读顺序：

1. [`paper-ready/00_PROJECT_SUMMARY.md`](paper-ready/00_PROJECT_SUMMARY.md)：当前阶段、证据强度、创新点和继续投入建议。
2. [`paper-ready/FREEZE_STATUS.md`](paper-ready/FREEZE_STATUS.md)：当前冻结范围、验证状态和未决边界。
3. [`paper-ready/README.md`](paper-ready/README.md)：论文版目录和数据分层。
4. [`docs/START_HERE.md`](docs/START_HERE.md)：方法、实验口径和限制的完整导航。
5. [`paper-ready/manifest.tsv`](paper-ready/manifest.tsv)：每类论文材料的唯一来源路径。

`paper-ready/` 是一个不复制原始数据的逻辑视图。原始日志、脚本和校验文件仍保留在原路径，以保证可复现性；旧版本、V2开发材料和smoke记录按清单排除，不应进入论文主表。
