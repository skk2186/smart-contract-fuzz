# V2 native ablation table

The machine-readable table is
[v2-native-ablation-summary.csv](v2-native-ablation-summary.csv). It is an
appendix/ablation data source, not a replacement for the frozen V1 main result.

The neutral mode measures path guidance without a known violating value. The
violation-boundary mode additionally instantiates values from the extracted
property predicate. Their aggregate rates therefore must not be pooled or
presented as one method.
