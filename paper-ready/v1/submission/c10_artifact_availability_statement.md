# Artifact Availability Statement

本研究的代码、实验配置、结果表、分析脚本和论文准备材料均可随论文 artifact 一并提供。可提供的材料包括冻结的实验 registry、结果 TSV、分析 summary、受控实验摘要、真实来源分层表以及 paper-ready draft materials。记录级结果用于复现统计口径和审阅证据边界。

本声明不意味着所有 raw artifact 均已公开，也不承诺将私人工作区、用户名、绝对路径或未整理的临时运行目录发布。正式提交前，研究者应根据会议的 artifact 规则决定公开内容、归档方式、许可证和可复现环境。

如采用匿名评审，应使用匿名化仓库或匿名 artifact 链接，移除 GitHub 用户名、私人仓库信息、本地路径和可识别的提交元数据。接收后再恢复正式作者归属和长期公开链接。
